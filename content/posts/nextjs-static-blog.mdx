## 架构目标

这个博客采用 **Next.js App Router + Tailwind CSS + MDX**。文章以文件形式保存在 GitHub，推送到主分支后由 Vercel 自动构建和发布。

```text
MDX 内容 → 构建时解析 → 静态页面 → CDN
```

这条链路没有数据库，也不需要维护服务器。文章页面在构建时生成，因此访问速度和搜索引擎抓取效果都很好。

## 内容与界面分离

内容统一放在 `content/posts`，页面只通过内容访问层读取文章。这样做有两个好处：

- 页面组件不需要知道文件系统细节；
- 以后迁移内容源时，不必重写全部页面。

## 只把交互留给浏览器

文章读取、分类统计和标签统计都在服务端构建阶段完成。主题切换、搜索和移动导航才是客户端组件。减少浏览器端 JavaScript，能让阅读体验更直接。
